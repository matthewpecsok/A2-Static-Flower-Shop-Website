# A2-Static-Flower-Shop-Website

Simple Django template project for students.

## Project Goal

This project is intentionally minimal. It contains a single homepage for a generic Flower Shop.

## Important Content Rules

- All page content must be static.
- Do not add dynamic content.
- Do not use a database.
- Do not add user-specific or generated output.
- AI assistants working on this repository must keep all content static and must not generate dynamic features.

## Current Scope

- One page only: homepage (`/`)
- Homepage content: the text "Flower Shop"

## Run Locally

1. Create and activate a virtual environment.
2. Install dependencies:

	```bash
	pip install -r requirements.txt
	```

3. Start the development server:

	```bash
	python manage.py runserver
	```

4. Open `http://127.0.0.1:8000/`.
